# Awesome Global FDE Roadmap

The goal is to make this repository the most useful open starting point for
people responsible for moving frontier AI into production and measurable
business outcomes.

## Phase 1 — Foundation

- [x] Publish mission, vision, values, governance, and contribution standards.
- [x] Establish the core FDE resource taxonomy.
- [x] Seed the list with high-quality first-party and standards-based sources.
- [x] Add structured resource suggestions and pull request templates.
- [x] Add repository metadata, social preview assets, and a searchable web page.

## Phase 2 — Field knowledge

- [ ] Publish an FDE 101 learning path in English and Chinese.
- [ ] Curate field discovery, technical scoping, and deployment playbooks.
- [ ] Create a production AI and agent architecture reading path.
- [ ] Add reusable templates for discovery, eval plans, rollout, and postmortems.
- [ ] Build a case index organized by industry, region, system, and evidence type.
- [ ] Invite the first group of practitioner reviewers.

## Phase 3 — Ecosystem map

- [ ] Track organizations with substantive FDE teams and role definitions.
- [ ] Publish a durable careers and competency guide rather than a short-lived job board.
- [ ] Build regional and Chinese-language collections with local context.
- [ ] Connect original Global FDE Field Notes, interviews, and research.
- [ ] Publish a transparent method for reviewing tools and commercial resources.

## Phase 4 — Shared infrastructure

- [ ] Provide machine-readable resource metadata.
- [ ] Automate broken-link and freshness checks without replacing human review.
- [ ] Publish periodic releases and changelogs for the curated collection.
- [ ] Produce an annual State of FDE report based on original field research.
- [ ] Maintain a public contributor and reviewer recognition system.

## Success criteria

This repository is working when practitioners use it to make real deployment
decisions, contributors share field evidence rather than promotion, and a new
FDE can find a credible path from role understanding to production delivery.

Suggestions are welcome through [issues](https://github.com/global-fde/awesome-global-fde/issues)
and [pull requests](https://github.com/global-fde/awesome-global-fde/pulls).
