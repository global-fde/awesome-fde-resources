# Awesome FDE Resources

[English](README.md) | [简体中文](README.zh-CN.md)

A focused list of high-quality resources for Forward Deployed Engineers and production AI delivery.

We prefer credible books, guides, production practices, real implementations, and tools that help move AI into real business workflows. Quality, relevance, maintenance, and practical value are reviewed together.

- [huggingface/agents-course](https://github.com/huggingface/agents-course) — Hands-on course for understanding and building AI agents.
- [ombharatiya/ai-system-design-guide](https://github.com/ombharatiya/ai-system-design-guide) — Production AI system design and evaluation guide.
- [PacktPublishing/LLM-Engineers-Handbook](https://github.com/PacktPublishing/LLM-Engineers-Handbook) — Practical LLM, RAG, deployment, and LLMOps handbook.

- [anmolksachan/AI-ML-Free-Resources-for-Security-and-Prompt-Injection](https://github.com/anmolksachan/AI-ML-Free-Resources-for-Security-and-Prompt-Injection) — Beginner roadmap for AI security and prompt injection testing.

- [business-science/awesome-generative-ai-data-scientist](https://github.com/business-science/awesome-generative-ai-data-scientist) — Resources for building and deploying GenAI applications.
